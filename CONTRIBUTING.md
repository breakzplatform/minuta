# Contributing

Issues and pull requests are welcome.

- Before a pull request is merged you will be asked to accept the
  [Contributor License Agreement](CLA.md). It keeps your copyright and lets
  the original author keep publishing official builds.
- Run `make test` before sending a change.
- A fork that is published separately needs its own name and icon; see
  [NOTICE](NOTICE) and [TRADEMARKS.md](TRADEMARKS.md).
