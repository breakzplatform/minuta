# Minuta on Haiku

A *minimal* Markdown editor in the spirit of **iA Writer**: one centered column of monospace text, the syntax visible but dimmed, and nothing else. The markers stay in the text. They are only drawn in a lighter gray, so the words come first.

## Focus

Focus mode dims everything except the sentence you are writing. The rest of the paragraph is still there. It just steps back. Move the caret and the light follows it.

> Writing is thinking. To write well is to think clearly.

## Code and lists

Inline `code` keeps the same font with its own color, and fenced blocks too:

```c
int main(void)
{
    return 0;
}
```

- ação, coração, pão, maçã
- é, ê, í, ó, ô, ú, ü, à
- [a link](https://www.haiku-os.org) and ~~a strikeout~~

1. first
2. second

## Typewriter

With typewriter scrolling the line with the caret stays in the middle of the window, so your eyes don't have to travel down the screen as the text grows. It is easier on the neck, and it keeps the next sentence in the same place.

Paragraph after paragraph, the text scrolls up and the caret stays put. The screen above is what you wrote; the screen below is empty space waiting for what comes next.

The end.
